# 🌦️ Weather App

A simple web application that provides weather information for a selected location.

## 💡 Overview

This project was built to learn how web applications can retrieve and display real-time information using an external API.

## ✨ Features

- 🔍 Search for a location
- 🌡️ Display current temperature
- 💧 Show humidity information
- 💨 Display wind information
- ☁️ Weather condition information
- 📱 Responsive interface

## 🛠️ Tech Stack

- **HTML**
- **CSS**
- **JavaScript**
- **Weather API**

## 📚 What I Learned

- Working with APIs
- Fetching and processing JSON data
- JavaScript asynchronous operations
- Updating webpage content dynamically
- Building a responsive interface

## 🚀 Future Improvements

- Extended weather forecasts
- Weather icons and animations
- Location-based weather detection
- Additional weather information
